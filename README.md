# JellyAmp PWA

A beautiful web music player for [Jellyfin](https://jellyfin.org). Desktop + mobile PWA.

![JellyAmp](public/logo.svg)

## Features

- 🎵 Stream your Jellyfin music library
- 📱 PWA — install on any device
- 🎨 Cypherpunk neon aesthetic
- ⌨️ Keyboard shortcuts (Space = play/pause, Shift+Arrow = next/prev)
- 🔊 Media Session API for OS-level controls
- 📴 Offline image caching
- 🔀 Shuffle, repeat, queue management

## Development

```bash
npm install
npm run dev
```

## Tech Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Jellyfin SDK
- Zustand (state management)
- Framer Motion (animations)
- Workbox (PWA / service worker)
